### Where to find them

1. ICMR official website: https://www.icmr.gov.in/
2. National Vector Borne Disease Control Programme: https://www.nvbdcp.gov.in/
3. National Nutrition Monitoring Bureau: https://www.nnmb.org/
4. Central TB Division: https://www.tbcindia.gov.in/

### Naming convention

Use descriptive names:
- `icmr_dengue_guidelines_2021.pdf`
- `icmr_tb_management_2022.pdf`
- `icmr_nutrition_guidelines.pdf`

After adding PDFs, run `python backend/ingest.py` to process them.
